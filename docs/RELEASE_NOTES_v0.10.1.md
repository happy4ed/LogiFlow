# LogiFlow 0.10.1

전환 관리 — 채널 박스 분실 방지 + 폭 정렬.

## 채널 박스 분실 방지

- 채널 박스를 끌 때 캔버스(pane) 밖으로 **나가지 못하게 clamp** — 안 보이는 곳으로 사라지는 일 없음.
- 모니터 변에 안 붙인 채 떨어뜨리면 **하단 미배치 트레이로 자동 복귀**(그 자리에 남지 않음) → 채널 2 같은 박스를 다시 못 찾는 문제 해결.

## 폭 정렬

- 채널 별칭 칩 3개를 **균등 폭**으로(채널 3 만 길게 튀어나오던 문제 해결). 캔버스·별칭·등록 기기·하단 막대가 모두 같은 폭.

## 유지

- 0.10.0 로그온 화면 접근 테스트(실험·읽기 전용) 그대로. 쓰기(전환)는 setHost 하나뿐·HostSwitcher 경유.
