# LogiFlow 0.12.4

## ARM 잠금화면 전환 안 됨 — 원인/수정 + 디버그 모드

**원인 발견**: ARM 은 Win+L 로 잠가도 입력 데스크톱이 "Winlogon" 이 아니라 **"Default" 로 보인다**(x86 은 Winlogon). 워커가 "보안 데스크톱 이름"만 보고 판정해서 ARM 잠금화면을 놓쳤다.

**수정**: 데스크톱 이름 대신 **세션 잠금 상태**로 판정.
- 사용자 세션이 잠김/해제(`SessionSwitch`)를 **플래그 파일**(`%ProgramData%\LogiFlow\locked.flag`)로 기록.
- 워커는 **잠김(플래그) 또는 보안 데스크톱(로그온 화면)** 일 때 전환 감지. 일반 unlock 상태는 사용자 세션이 담당(이중 전환 방지). → ARM·x86 둘 다 커버.

## 상세 디버그 로그(상세 로그)

설정 → 전환·진단 → **「상세 디버그 로그」** 켜기. 로그온 전환 워커가 매 ~0.4초마다 기록:
`desktop=.. secure=.. locked=.. active=.. cursor=(x,y) | <모니터> <변> dist=.. band=.. dwell=..`
+ 시작 시 모니터 경계·등록된 엣지. → 전환이 왜 안 되는지(엣지 0개·좌표 안 맞음·잠금 미감지·HID) 바로 추적.

## 즉시 적용

- 「로그온 전에도 실행」 켜면 **지금 바로 워커 실행**(재부팅 전 Win+L 로 시험 가능). 디버그 토글은 몇 초 뒤 반영.
