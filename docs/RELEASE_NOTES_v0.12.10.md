# LogiFlow 0.12.10

## "로그온 전에도 실행" 토글이 "설치 실패/취소" 뜨던 문제

0.12.9 에서 예약 작업을 XML 로 만들게 바꿨는데, schtasks `/Create /XML` 이 거부되면 **폴백이 없어 토글이 그대로 실패**했다.

수정:

- **실패 시 폴백** — XML 생성이 거부되면 종전(0.12.8) 방식(부팅 ONSTART)으로라도 작업을 만들어 **토글이 실패하지 않게**. (이 경우 배터리 조건은 남아 콜드부팅-배터리에서만 제약 — 수동 토글·로그인 후엔 동작.)
- **schtasks 오류를 로그에 기록** — `/XML` 이 왜 거부됐는지 schtasks 출력을 `desktop-probe.log` 에 남긴다([진단 → 로그 열기]로 확인). 다음 판에서 정확히 교정.
- XML 명령에서 `/RL` 제거(XML Principal 의 RunLevel 과 충돌 소지) · `/RU SYSTEM` 유지.

## 목표는 그대로

배터리 조건 제거 + 부팅·로그온 2중 트리거(콜드부팅 로그온 화면 자동 동작)가 목표. XML 이 통과하면 그 전체가 적용되고, 거부돼도 최소한 0.12.8 수준으로 떨어져 토글은 된다.

## 적용법

설치 후 **설정 → "로그온 전에도 실행" 껐다 켜기**. 이제 실패 메시지 없이 설치된다. 한 번 켠 뒤 **[진단 → 로그 열기]** 에서 맨 아래 `작업 생성(... ) rc=` 줄을 보면 XML(2중 트리거)로 됐는지 폴백(ONSTART)으로 됐는지 알 수 있다 — 그 줄(과 schtasks 실패 줄이 있으면 그것도) 한 줄 주시면 XML 거부 원인 바로 잡겠음.
