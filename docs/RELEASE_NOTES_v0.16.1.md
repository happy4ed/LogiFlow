# LogiFlow 0.16.1 — 세 OS 같은 판(Windows · Mac · Linux)

0.16.0 뒤 첫 사용 점검에서 남았던 화면 다듬기 13건을 고치고, Mac 클립보드 암호문구를 키체인에 넣었다. Windows · Mac · Linux 가 같은 판 번호(0.16.1)다. 하는 일(가장자리로 밀어 채널 전환 · 클립보드 공유)은 그대로다.

## 받을 파일

| 파일 | 내용 |
|---|---|
| `LogiFlow-windows-setup.exe` · `LogiFlow-v0.16.1-setup.exe` | Windows 설치 파일(x64 · ARM64 한 파일, 같은 파일 두 이름) |
| `LogiFlow-v0.16.1-win.zip` | Windows 설치 없이 쓰는 실행 파일 |
| `LogiFlow-mac.dmg` · `LogiFlow-v0.16.1-mac.dmg` | Mac 앱(Apple Silicon · Intel 한 파일, 같은 파일 두 이름) |
| `LogiFlow-v0.16.1-mac.zip` | 같은 Mac 앱 zip |
| `LogiFlow-linux-x64.tar.gz` · `LogiFlow-v0.16.1-linux-x64.tar.gz` | Linux 명령줄(x64) |
| `LogiFlow-linux-arm64.tar.gz` · `LogiFlow-v0.16.1-linux-arm64.tar.gz` | Linux 명령줄(arm64) |
| `*-SHA256SUMS.txt` | 해시(OS 마다) |

## 올리기

- Windows: 0.16.0 위에 그대로 설치하면 제자리에서 바뀐다(설정 그대로 · 설치된 앱 목록에 항목 하나).
- Mac: 0.16.0 `LogiFlowRs.app` 을 새 것으로 바꿔 넣는다. 서명 없는 앱이라 처음 한 번 막힌다 —
  macOS 14 이하는 Control-클릭 → 「열기」, macOS 15 이상은 시스템 설정 → 개인정보 보호 및 보안 → 「그래도 열기」
  (또는 `xattr -dr com.apple.quarantine /Applications/LogiFlowRs.app`).
- Linux: 압축을 풀고 `sudo ./install.sh`(실행 파일 `logiflow-rs` + udev 규칙).

Mac 만: 기록 폴더 설명 「기록 파일이 든 폴더를 Finder 에서 엽니다.」(내부 이름 LogiFlowRs 경로를 보이지 않음) · 테마 설명 「자동은 macOS 설정을 따르고, 라이트·다크는 고정합니다.」

조사 띄어쓰기(「PC 가」 · 「LogiFlow 를」)는 그대로 둔다 — 영문 낱말 뒤 조사를 한 칸 띄우고 그 칸을 줄바꿈 안 되는 공백으로 묶어 조사만 다음 줄로 떨어지지 않게 하는 규칙(`paint::keep_together`)이라, 붙이면 영문 낱말과 조사가 줄 끝에서 갈라질 수 있다. Mac 화면은 0.16.0 처럼 「이 Mac」 · 「컴퓨터」로 바뀌며 조사도 끝소리에 맞춘다.

### Mac 클립보드 암호문구 → 키체인

- 암호문구를 로그인 키체인에 넣는다(항목: 서비스 `com.happy4ed.logiflow.rs` · 계정 `clipSecret`). `config.txt` 에는 `clipSecretDpapi=keychain` 표시만 남는다.
- 0.16.0 Mac 판이 `config.txt` 에 평문으로 둔 암호문구는 처음 실행 때 키체인으로 옮기고, 다시 읽어 같은지 확인한 뒤 파일에서 지운다.
- 키체인이 실패하면 평문으로 대신 쓰지 않는다.
  - 저장 실패: 파일에는 암호문구를 쓰지 않는다(지금 켜져 있는 동안은 메모리 값으로 주고받음). 설정 창 암호문구 줄에 「키체인에 저장하지 못함 — 지금은 주고받지만 앱을 다시 켜면 다시 넣어야 합니다」, 알림 한 번.
  - 읽기 실패: 암호문구 없이 시작하고 같은 줄에 「키체인에서 읽지 못함 — 암호문구를 다시 넣어 주세요」.
  - 옮기기 실패(0.16.0 평문): 파일을 그대로 둔다(암호문구를 잃지 않게) · 다음 실행에 다시 옮긴다.
- 서명 없는 앱이라, 새 판으로 바꾼 뒤 처음 키체인을 읽을 때 macOS 가 「LogiFlowRs 이(가) 키체인의 정보를 사용하려고 합니다」를 물을 수 있다 → 「항상 허용」.
- 암호문구를 비우면 키체인 항목도 지운다.

### 그 밖

- 판 번호 0.16.1(세 OS). Windows 는 0.16.0 과 같은 앱 id 라 덮어 설치된다.
- 고정 이름 파일을 함께 낸다(`LogiFlow-windows-setup.exe` · `LogiFlow-mac.dmg` · `LogiFlow-linux-x64.tar.gz` · `LogiFlow-linux-arm64.tar.gz`). Linux 파일 이름 앞부분이 `LogiFlowRs-` 에서 `LogiFlow-` 로.
- Mac HID: 출력 리포트 길이를 Windows 와 같은 뜻(장치가 알려 준 값 그대로)으로.

클립보드 프레임 · 키 · `config.txt` · `devices.txt` 형식은 바뀌지 않았다(C# 판 · 0.16.0 과 주고받음).
