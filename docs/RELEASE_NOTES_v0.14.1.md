# LogiFlow+ 0.14.1 (B안 테스트 프리릴리스)

**정식 아님 — B안 실기 테스트용.** 0.14.0 에서 지적된 바탕화면 glow 누락을 고침.

## 수정 — 바탕화면 glow 복구

0.14.0 에서 트레이 엣지 감시를 끄면서 바탕화면 glow(변에 닿을 때 빛나는 효과)가 빠졌었다.
이제 **서비스 바탕화면 워커(raw)가 glow 오버레이를 직접 그린다** — 트레이가 하던 것과 동일한
GlowController 를 워커에 연결. 변에 닿으면 빛나고 전환 순간 pop 하는 효과가 바탕화면에서도
다시 나온다.

## 나머지 B안 동작(0.14.0 그대로)

- 서비스가 바탕화면 전환 전담(로그인 직후 공백 제거). 로그온/잠금 = 폴링 워커, 바탕화면 = raw 워커.
- raw input(실제 밀기) 판정 → 커서를 가장자리에 둬도 오작동 없음.
- "로그온 전에도 실행" 켜면 트레이 엣지 감시 끔(중복 방지).

## 테스트

1. 0.14.1 설치 → "로그온 전에도 실행" 켜기.
2. 바탕화면에서 변에 커서 대면 **glow 가 다시 뜨는지**.
3. (0.14.0 테스트 포인트 그대로) 로그인 직후 공백 없는지 · 가장자리에 둬도 오작동 없는지 · 로그온/잠금 전환 · 중복 전환 없는지.
