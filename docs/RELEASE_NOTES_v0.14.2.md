# LogiFlow+ 0.14.2 (B안 테스트 프리릴리스)

**정식 아님 — B안 실기 테스트용.** 0.14.1 에서 지적된 바탕화면 glow 타이밍을 고침.

## 수정 — glow 는 넘어가기 직전 가장 밝고, 넘어가는 순간 사라짐

0.14.1 증상: 전환은 되는데 넘어가고 나서야 밝은 빛이 나오고, 파란 변이 화면에 남음.

원인 두 가지:

1. 바탕화면 워커가 setHost(기기당 ping + 확인 대기 약 0.5초)를 화면 그리는 스레드에서
   돌려, 그동안 glow 가 마지막 프레임에 멈췄다가 전환이 끝난 뒤에야 전환 pop 이 그려짐.
2. 전환 직후 남아 있던 마우스 입력이 진행 0 으로 glow 를 다시 켜고, 진행 0 에서도 얇은
   띠·선을 그림. 넘어간 뒤 이 PC 엔 입력이 더 안 와서 끌 기회가 없어 파란 변이 남음.

고친 것:

- 전환은 별도 스레드에서 실행 — glow 가 멈추지 않음.
- 밝기는 dwell 85% 에서 최대 → 전환 직전까지 최대 유지. 전환 순간 즉시 숨김(전환 뒤 pop 없음).
- 진행 0 이면 아무것도 안 그림. 전환 직후 변에서 16px 떨어지기 전에는 glow 안 켬.

## 테스트

1. 0.14.2 설치("로그온 전에도 실행" 켠 상태 유지).
2. 바탕화면에서 변으로 밀기 → glow 가 점점 밝아져 **넘어가기 직전 최대**인지.
3. 넘어가는 순간 **빛이 바로 사라지고 파란 변이 안 남는지**.
4. 다시 돌아온 뒤 커서가 변에 붙어 있어도 glow 가 안 뜨는지(조금 떼었다 다시 밀면 정상).
