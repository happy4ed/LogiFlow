# LogiFlow 0.13.4

회장님이 0.13.3 쓰시고 지적하신 모달·스크롤 두 가지를 고쳤습니다.

## ① 모달 = 한 창에서 진행 → 결과 → 확인 (팝업 두 번 금지)

0.13.3 은 "로그온 전에도 실행" 토글 때 **진행 모달이 닫힌 뒤 또 OK 팝업**이 떠서 불쾌했다.

- 이제 모달이 닫히지 않는다. 처리가 끝나면 **같은 창에서** 진행 막대가 사라지고 본문이 결과 메시지로 바뀌며 **[확인] 버튼**이 나타난다. [확인]을 눌러야 닫힌다.
- 팝업 사라지고 또 다른 팝업 뜨는 현상 제거.

## ② 라이선스 보기 = 테마 스크롤바

오픈소스 라이선스 창 스크롤이 **윈도우 기본 스크롤바**였다. 이제 앱 테마에 맞춘 **얇은 테마 스크롤바**(`ThemedScrollPanel`)로 바뀌어 다른 화면과 톤이 같다.

## 유지

0.13.0 윈도우 서비스(콜드부팅 상주)·0.13.1 churn 수정·0.13.2 로그온 트레이 예약 작업·0.13.3 라이선스 메뉴 그대로. 콜드부팅 로그온 화면 전환은 실측 확인됨(마우스·키보드 2/2).

## 데스크탑 공백에 대해

로그인 직후 바탕화면에서 트레이가 뜰 때까지의 공백은 B안(예약 작업 자동시작)으로 줄일 수 있는 한계까지 왔습니다. 완전 0 으로 하려면 서비스가 데스크탑까지 raw 입력으로 직접 전담하는 **A+** 가 필요하고, 이는 작업·리스크가 큰 별도 건입니다.

## 적용

0.13.4 설치 → "로그온 전에도 실행" 껐다 켤 때 모달이 **한 창에서** 결과까지 보여주는지, 설정 맨 아래 라이선스 [보기] 스크롤이 테마 스크롤바인지 확인.
