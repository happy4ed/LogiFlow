# LogiFlow 0.4.0

승인된 UX 시안대로 앱을 다시 꾸미고 기능 추가.

## 디자인 반영

- 승인 시안(design/ v2)의 레이아웃·토큰·컴포넌트를 WinForms 로 구현. 사이드바 내비
  (전환 관리 · 설정 · 진단) + 콘텐츠. macOS풍 라운드 그룹·토글(28x16)·세그먼트·배지·카드를
  커스텀 페인팅(LocalDex ThemedButton 식).
- 테마 토큰(brief v3) Light/Dark 전체 적용. 테마는 시스템/라이트/다크(기본 시스템) 선택·저장.
- 고정 창 크기(기본 900x600, 리사이즈·최소크기 허용). 페이지를 바꿔도 창 크기 안 바뀜,
  내용 많으면 스크롤.

## 화면

- 전환 관리: 모니터 배치 캔버스(실제 Screen.AllScreens + 채널 PC 박스=모니터 크기 사각형을
  변에 드래그 스냅, 접촉=파랑 자동·분리=점선 회색 수동) · 채널 별칭(편집·저장) · 기기 목록
  (마우스/키보드 다른 아이콘·현재 채널·전환) · 가장자리 자동 전환(대기 0.33초·드래그 중 전환
  안 함·배치 초기화).
- 설정: 테마 · Windows 시작 시 실행 · 로그온 전에도 실행(고급·준비 중 안내) · 가장자리 자동
  전환 사용 · 진단 로그 남기기.
- 진단: 기기 스캔 표(기기·VID:PID·연결·0x1814·채널) + 모두 보기 + 새로 고침 + 로그 폴더 열기.

## 기능 추가

- 앱 아이콘: 시안 "두 화면 사이 흐름" 마크를 .ico(16·24·32·48·64·128·256)로 생성, 앱 exe·창·
  트레이·설치파일에 적용. 로지텍 로고 아님.
- 기기 정보 캐시: 스캔 결과를 %APPDATA%\LogiFlow\devices.txt 에 저장 → 시작 시 캐시로 바로
  표시, 매번 재검색 안 함. 새로 고침·기기 변화(WM_DEVICECHANGE, 지문 비교) 때만 재스캔.
- 트레이 우클릭: 채널 별칭 포함 바로 전환(현재 채널 제외) + 설정 열기 + 새로 고침 + 종료.
  현재 채널을 트레이 툴팁에 표시.
- 설치파일: Inno Setup per-user 설치(build/windows/LogiFlow.iss). 설정은 %APPDATA% 라
  업데이트·제거 시 보존. CI(windows-latest)가 setup.exe + ZIP + SHA256 생성.
- 채널 별칭·배치·테마·토글은 %APPDATA%\LogiFlow\config.txt 저장.

## 안전

- 쓰기는 0x1814 func1 setHost 하나뿐, HostSwitcher 경유만(0x1814 지원·0~hostCount-1 범위·명시
  트리거=엣지 or 버튼). 그 외 쓰기 없음. 가장자리 자동 전환은 설정에서 끌 수 있음.
