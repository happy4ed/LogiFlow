# LogiFlow 0.13.0

## "로그온 전에도 실행" = 윈도우 서비스로 전환 (콜드부팅 대응 · 핵심)

여태 스케줄 작업 BootTrigger 가 **콜드부팅에서 안 떠서**(로그온 화면 전에 워커 미실행) 전환이 안 됐다. 이제 **윈도우 서비스**(`LogiFlowLogonSwitch`, LocalSystem·자동시작)로 바꿨다. 서비스는 **콜드부팅 포함 모든 부팅에서 로그인 전에 상주**한다(빠른 시작 무관).

- 서비스(세션0)가 **활성 콘솔 세션의 winlogon 데스크톱에 워커를 투입**하고, 세션이 바뀌면(로그인·사용자 전환) 기존 워커를 종료하고 새 세션에 **재투입**한다.
- 전환 쓰기 경로는 그대로 하나(`HostSwitcher` · 0x1814 setHost) — 안전 가드 유지.
- 설치/삭제는 advapi32(CreateService/DeleteService) 직접 호출(sc.exe 따옴표 문제 회피). 구버전 스케줄 작업은 설치 시 자동 제거(이중 투입 방지).
- 토글 상태 표시는 서비스 존재 여부로 판정(표준 권한 조회).

## 적용법 (중요)

설치만으론 서비스가 안 바뀐다 — **설치 후 설정 → "로그온 전에도 실행" 껐다 켜기**(이때 서비스가 등록·시작됨). 그다음:

1. **완전 종료 후 전원 켜기(콜드부팅)**.
2. 로그온 화면(로그인 전)에서 마우스 깨워 오른쪽 변으로 밀기.
3. 로그(`desktop-probe.log`)에 `[서비스] supervisor 시작` → `[서비스] 워커 투입 …` → 밀면 `[로그온 전환] … setHost 전환 N/…개` 가 떠야 함.

이제 로그인 한 번 없이 **콜드부팅 직후 로그온 화면**에서 서비스가 떠 있으니, 기기만 깨어 있으면(마우스 흔들기) 전환돼야 한다.
