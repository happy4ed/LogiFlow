# LogiFlow 0.12.0

## 로그온/잠금 화면에서도 전환 (실제 기능)

프로브로 "winlogon 보안 화면에서 커서·HID 읽기 가능"을 확인한 뒤, **실제 전환 기능**을 넣었다.

- 설정 → 실행 → **「로그온 전에도 실행」 켜기**: UAC 승인 후 부팅 시(ONSTART) SYSTEM 작업 설치.
- 부팅 시 SYSTEM 런처가 콘솔 세션 **winlogon 데스크톱에 전환 워커**를 띄운다. 워커는 **보안 화면(잠금/로그인)일 때만** GetCursorPos 폴링 → 기존 `EdgeDetector`(띠·dwell·바깥밀기)로 가장자리 판정 → `setHost` 전환. (일반 로그인 화면은 사용자 세션 앱이 담당 — 이중 전환 방지)
- [전환 관리]에서 붙인 **채널 배치를 머신 공유 설정**(`%ProgramData%\LogiFlow\logon-edges.txt`)으로 내보내 워커가 읽는다. 배치를 바꾸면 자동 갱신.
- 동작·판정은 `desktop-probe.log` 에 기록(`[로그온 전환] … setHost 전송 N개`). 안 되면 로그로 원인 추적.
- **한계**: 리시버/동글이 그 PC 에 있어야 함 · 관리자 권한 필요 · 다음 부팅부터 완전 적용(지금은 Win+L 로도 시험). 쓰기(전환)는 여전히 HostSwitcher setHost 하나.
- 이로써 "노트북(로그인 화면)에서 내 PC 로 돌아오기"가 가능해진다(그 PC 에 이 기능 켜져 있으면).

## 클립보드 공유 — 진단 도구

설정 → 클립보드 공유: **이 PC 주소 표시 · [연결 테스트] · [테스트 보내기](상대서 Ctrl+V 확인) · [방화벽 허용](netsh) · 받으면 트레이 알림**. 안 될 때 어디서 막히는지(주소·방화벽·도달·암호문구) 바로 보인다.
