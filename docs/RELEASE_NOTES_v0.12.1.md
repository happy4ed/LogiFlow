# LogiFlow 0.12.1

## 클립보드 공유 — 원인 추적 진단 강화

- **암호문구 불일치 알림**: 데이터는 받았는데 복호·인증 실패(HMAC)면 트레이 경고 "양쪽 암호문구가 다릅니다".
- **송수신 로그**: 복사 시 "클립보드 변화 감지 → 전송 시도", "전송 성공/실패(사유)", 수신 시 "프레임 수신 N바이트" 를 진단 로그에 남김.
  → 복사했는데 동작 안 하면 로그로 바로 구분: 감지 안 됨(리스너)·전송 실패(도달/방화벽)·인증 실패(암호문구)·수신됨(정상).

## 증상별 대처

- **상대→이 PC 연결 테스트 실패**: 이 PC 인바운드가 막힘 → 이 PC 에서 [방화벽 허용]. 회사 정책이면 IT 경로.
- **연결은 되는데 복사 안 됨**: 거의 암호문구 불일치 → 양쪽을 똑같이 다시 설정(불일치면 받는 쪽에 경고 알림이 뜸).
