# LogiFlow 0.16.2 — 세 OS 같은 판(Windows · Mac · Linux)

0.16.1 노트 「남은 일」에 적어 둔 화면 다듬기 11건을 고쳤다. Windows · Mac 이 같이 쓰는 설정 창만 바뀌었고, 하는 일(가장자리로 밀어 채널 전환 · 클립보드 공유)은 그대로다. Windows · Mac · Linux 판 번호는 모두 0.16.2 다.

## 받을 파일

| 파일 | 내용 |
|---|---|
| `LogiFlow-windows-setup.exe` · `LogiFlow-v0.16.2-setup.exe` | Windows 설치 파일(x64 · ARM64 한 파일, 같은 파일 두 이름) |
| `LogiFlow-v0.16.2-win.zip` | Windows 설치 없이 쓰는 실행 파일 |
| `LogiFlow-mac.dmg` · `LogiFlow-v0.16.2-mac.dmg` | Mac 앱(Apple Silicon · Intel 한 파일, 같은 파일 두 이름) |
| `LogiFlow-v0.16.2-mac.zip` | 같은 Mac 앱 zip |
| `LogiFlow-linux-x64.tar.gz` · `LogiFlow-v0.16.2-linux-x64.tar.gz` | Linux 명령줄(x64) |
| `LogiFlow-linux-arm64.tar.gz` · `LogiFlow-v0.16.2-linux-arm64.tar.gz` | Linux 명령줄(arm64) |
| `*-SHA256SUMS.txt` | 해시(OS 마다) |

## 올리기

- Windows: 0.16.1(또는 0.16.0) 위에 그대로 설치하면 그 자리에서 바뀐다. 설정은 그대로이고, 설치된 앱 목록에도 항목이 하나만 남는다.
- Mac: `LogiFlowRs.app` 을 새 것으로 바꿔 넣는다. 서명 없는 앱이라 처음 한 번은 실행이 막힌다.
  - macOS 14 이하: Control-클릭 → 「열기」
  - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 → 「그래도 열기」
  - 또는 `xattr -dr com.apple.quarantine /Applications/LogiFlowRs.app`
- Linux: 압축을 풀고 `sudo ./install.sh` 를 실행한다(실행 파일 `logiflow-rs` + udev 규칙).

## 바뀐 것(Windows · Mac 같은 설정 창)

| 무엇이 불편했나 | 어떻게 |
|---|---|
| 「자세히 보기」를 눌러도 번호만 나오고, 「전환 기능 위치 10」은 뜻을 알 수 없음 · 파란 링크가 머리보다 큼 | 링크 이름을 「문의용 번호 보기」 · 「문의용 번호 숨기기」로 바꿨다. 기기마다 「문의용 번호 046D:C548 · 1 · 10」처럼 이름 없이 묶어 보이고, 펼쳤을 때만 「문제를 알릴 때 함께 보내는 번호라 평소에는 신경 쓰지 않아도 됩니다」를 붙인다. 링크는 머리줄에서 카드 안 설명 아래로 옮겨 다른 링크(「진단 화면에서 테스트하기」)와 같은 크기다 |
| 묶음 모양이 세 가지(카드 있음 · 없음 · 머리에 개수+링크+버튼) | 세 화면 모두 같은 규칙: 머리에는 이름만(「기기」) 두고 내용은 모두 카드 안에 넣는다. 「채널 이름」 · 「기기」도 카드가 됐다. 찾은 개수 · 「다시 찾기」 · 「문의용 번호 보기」는 카드 첫 줄로 옮겼다. 묶음 사이는 24, 머리와 카드 사이는 8 로 맞췄다. 「이 기기만 전환」 · 「모두 전환」은 같은 폭이다 |
| 「비우면 「채널 N」으로 돌아갑니다」 · 비운 칩에 「이름 없음」 | 「비우면 원래 이름(예: 채널 3)으로 돌아갑니다」로 바꿨다. 이름을 비운 칩에는 「채널 3」만 보인다. 이름 입력 상자도 「비우면 원래 이름 「채널 3」」으로 맞췄다 |
| 이름 없는 채널 상자에 모니터 아이콘 → 「모니터 1」과 같은 종류로 읽힘 | 이름이 없으면 동그라미 안에 채널 번호만 넣은 아이콘을 쓴다. 노트북 낱말이 든 이름은 노트북 아이콘이다(규칙 그대로) |
| 모니터 상자 아래 「이 PC」 → 모니터 1 이 채널 1 로 오해됨 | 「이 PC · 채널 1」(Mac 은 「이 Mac · 채널 1」)로 바꿨다. 채널 번호는 기기가 지금 가리키는 이 컴퓨터의 채널이다. 한 줄에 들어가지 않으면 「이 PC」 / 「채널 1」 두 줄로 나눈다 |
| Windows: 같은 대상을 「기존 LogiFlow」 · 「이전 판」 · 「남아 있는 이전 판」으로 부름 · 「정리」가 가볍게 들림 | 이름을 「이전 판」 하나로 맞췄다. 버튼 이름은 「이전 판 지우기」다. 하는 일은 0.16.0 의 「기존 LogiFlow 정리」와 같고 이름만 바뀌었다. 진단 카드는 머리 「이전 판」 · 제목 「남은 것」 · 주황 줄(남은 것 목록)로 줄였다. 확인 상자 · 진행 창 · 알림 · 설치 화면의 글도 같은 이름을 쓴다 |
| 주소 칸 이름이 두 OS 에서 달라 괄호 보충(「(Mac 은 「이 Mac 주소」)」)이 붙음 | 두 OS 모두 「이 컴퓨터 주소」 · 「상대 컴퓨터 주소」로 바꾸고 괄호를 뺐다. 클립보드 공유 묶음과 연결 확인 글에서도 상대는 「상대 컴퓨터」라고 쓴다 |
| 「이 PC 의 다른 주소」에 주 주소와 같은 「복사」가 늘 보임 | 다른 주소는 기본으로 접어 두고, 첫 주소 아래 「다른 주소 보기」 링크로 편다. 펼치면 다른 주소에도 같은 「복사」 버튼이 있다(같은 동작은 같은 모양) |
| 진단 「진단 기록 남기기」와 「상세 기록」이 따로 노는 것처럼 보임 | 코드를 확인해 보니 실제로 따로 동작한다. 「진단 기록 남기기」는 트레이가 설치 폴더 `logs` 에 쓰는 기록이고, 「상세 기록」은 로그인 전 실행 서비스가 로그인 화면 기록에 커서 위치를 더 쓰는지만 정한다. 앞을 꺼도 상세 기록은 남는다. 그래서 들여 쓰거나 흐리게 하지 않고, 이름을 「로그인 화면 상세 기록」으로 바꿔 남는 곳과 「따로 켜고 끕니다」를 설명에 적었다 |
| Mac 글자 「작게」의 설명 글이 13px 아래로 보임 | Mac CI 에서 앱이 직접 잰 값: 설명 글 em 13.00 논리 px(CI 화면 배율 1.0 — 레티나 2.0 이면 26 화소 = 13 논리 px), 줄 높이 16, 한글 한 자 폭 11.24. 13px 하한을 지키고 있어 크기는 바꾸지 않았다. 작아 보이는 까닭은 글꼴이다: 같은 글(「같은 네트워크에 있는 상대」)이 Windows(맑은 고딕) 151px · Mac(Apple SD 산돌고딕 Neo) 132px 로, 같은 13px 에서 Mac 한글이 약 13% 좁다(글자 높이는 11 · 11~12px 로 비슷) |
| 글자 「크게」에서 「모니터 1」 상자 여백이 약 6px | 모니터 상자 폭이 글자에 맞춰 늘어난다. 좌우 여백은 16 이상이고, 캔버스 폭을 넘지 않는 데까지만 늘린다. CI 캡처 실측(상자 안쪽 흰 면 기준 왼쪽/오른쪽): Windows 작게 18/18 · 보통 18/18 · 크게 18/19, Mac 작게 17/17 · 보통 17/17 · 크게 17/17(0.16.1 Windows 는 18/19 · 13/14 · 8/10). 상자 폭은 116 · 132 · 148px |

클립보드 프레임 · 키 · `config.txt` · `devices.txt` 형식은 바뀌지 않았다. C# 판 · 0.16.x 와 그대로 주고받는다.

## 첫 사용 점검(바뀐 화면 · Windows · Mac 캡처, 11-16)

차단 0 · 중요 10 · 다듬기 7. 이번 판에서 고친 것(중요 4건):

| 지적 | 어떻게 |
|---|---|
| 「이전 판 지우기」가 두 곳에 있고 설명이 다름 · 「앱」이 지금 쓰는 LogiFlow 인지 모름 | 전환 관리 알림 · 진단 카드 · 확인 상자의 설명을 한 문장으로 맞췄다: 「이전 판 앱·로그인 전 실행 서비스·예약 작업·자동 시작 항목·남은 파일을 지웁니다. 지금 쓰는 LogiFlow 와 설정은 그대로 남습니다. 관리자 승인이 한 번 필요합니다.」 두 곳에 두는 것은 그대로다(전환 관리는 「멈춤」일 때만 나오는 알림, 진단은 남은 것이 있으면 늘 보임) |
| 다른 주소의 「복사」만 링크 모양 | 버튼으로 맞췄다(접혀 있어 늘 보이지는 않음) |
| 기기를 못 찾았을 때 안내가 스크롤 맨 아래 단추를 가리킴 | 「다시 찾기」를 캔버스 안 안내 바로 옆에 두고, 이때는 「기기」 묶음의 「다시 찾기」를 숨긴다(진입점은 늘 하나). 「크게」에서 안내가 길어지면 캔버스를 늘려 모니터와 겹치지 않게 했다 |
| 클립보드: 상대 주소와 이 컴퓨터 주소가 떨어져 있고 설명이 서로를 가리킴 | 「상대 컴퓨터 주소」 바로 아래 「이 컴퓨터 주소」(암호문구는 그 뒤). 설명은 「상대 컴퓨터 설정 창에 보이는 「이 컴퓨터 주소」를 넣습니다」 · 「이 주소를 상대 컴퓨터의 「상대 컴퓨터 주소」에 넣으세요」로 줄였다(「(포트는 넣지 않음)」도 뺌) |

## 남은 일

화면 구조 · 용어를 바꾸거나 새 기능이 드는 것이라 이번 판(다듬기)에서는 고치지 않았다. 회장님 판단이 필요하다.

- 중요(점검이 「중요」로 봄)
  - 「이 기기만 전환 ⌄」 · 「모두 전환 ⌄」이 바로 위 「0.33초 ⌄」(값 고르기)와 같은 모양이라 설정값으로 읽힘. 누르면 받을 채널 메뉴 → 확인 상자(「전환하면 이 PC 에서는 이 기기를 쓸 수 없습니다」)가 떠서 바로 넘어가지는 않는다. 이름 · 모양을 바꾸는 일은 아래 「전환」 용어 정리와 같이 해야 한다
  - 사이드바에 클립보드 공유가 없음(「설정」 세 번째 묶음) → 「클립보드 공유」 화면을 따로 두는 구조 개편
  - 「전환」이 화면 이름 · 묶음 · 동작 · 상태에 모두 쓰임 → 자동은 「넘기기」, 직접은 「보내기」 같은 용어 정리(트레이 메뉴까지)
  - 「로그인 전에도 실행」이 앱을 미리 띄운다는 뜻으로 읽힘 → 이름 · 자리(전환 관리로) 바꾸기
  - 로그인 화면 관련 조작이 세 곳(설정 · 진단 두 곳)에 흩어짐 → 한 묶음으로
  - 클립보드 상대 컴퓨터와 채널 이름이 이어지지 않음(주소 숫자만) → 새 기능
- 다듬기
  - 「문의용 번호」를 진단 화면으로 옮기기
  - 클립보드 「사용」의 「아직 못 씀 — 암호문구를…」과 암호문구 줄 「아직 없음」이 같은 상태를 두 번 알림
  - 방화벽 「허용」 · 「허용 해제」 → 「포트 열기」 · 「포트 닫기」
  - 상대 주소 옆 「⋮」(Mac 「⋯」) 안 항목이 「지우기」 하나뿐 → 꺼내기
  - 설명 군더더기(「넘어가기 전 대기」 세 문장 · 「누르면 바꿀 수 있고」 · 화면 제목 밑 묶음 이름 나열)
  - 영문 뒤 조사 띄어쓰기(「PC 가」) — 0.16.1 노트대로 줄바꿈 규칙(`paint::keep_together`) 때문에 유지
  - 채널 상자를 끌 수 있다는 단서(마우스를 올리면 손 모양 커서는 이미 바뀜 — 정지 캡처라 안 보임) · 「배치 처음으로」(새 기능)
- Mac 「작게」 글자: em 은 13px 이지만 한글이 Windows 보다 약 13% 좁게 보인다. 맞추려면 Mac 글꼴 배율을 따로 둬야 한다(이번 판은 규칙(13px 하한)대로 두었다)
