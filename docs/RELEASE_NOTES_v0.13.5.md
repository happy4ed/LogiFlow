# LogiFlow 0.13.5 — 윈도우판 1차 마무리

## 버그 수정 — 라이선스 창 휠 스크롤

라이선스 창을 띄우고 마우스 휠을 돌리면 **라이선스가 아니라 뒤의 메인 창**이 스크롤되던 버그 수정. 테마 스크롤 패널이 휠 메시지를 전역으로 가로채다 보니, 모달 라이선스 위에서 돌린 휠을 뒤에 가린 메인 창 패널이 먼저 먹었다. 이제 **자기 창이 활성 창일 때만** 휠을 처리한다 → 라이선스 창 위 휠은 라이선스가 스크롤된다.

## 크로스플랫폼(Mac/Linux) 작업 계획 추가

지금은 Mac/Linux 런타임 확인이 불가능해, **지원 가능하도록 길을 닦는 계획서**를 넣었다(`docs/CROSS_PLATFORM_PLAN.md`). 요지:

- 전환의 본질(HID++ 0x1814 Change Host)은 **OS 독립 프로토콜** — OS마다 다른 건 "그 HID 리포트를 어떤 API로 써 보내느냐"뿐.
- 목표 구조 = **코어(프로토콜·전환·엣지 계산) / OS별 어댑터(HID 전송·입력·모니터·상주·UI)** 분리. 전환 로직은 한 번만 맞으면 전 OS 공유.
- 다음 안전한 선작업 = **코어 추출**(윈도우에서 결과 동일성 검증 가능). OS 어댑터 실코드는 해당 OS에서 검증 가능해질 때 단계적으로.
- 검증 불가 대량 코드 선작성은 하지 않음(과설계 금지).
