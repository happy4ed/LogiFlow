# LogiFlow 백로그 (다음 판 할 일)

## UX (회장님 지시 2026-10-23)

1. **즉시 끝나지 않는 토글·동작은 반드시 모달(modal) 표시**
   - 대상: "로그온 전에도 실행" 토글(UAC 상승 + schtasks 작업 생성/삭제 + /Run), 방화벽 허용 등 백그라운드로 몇 초 걸리는 모든 동작.
   - 요구: 누르면 **모달을 띄우고 "설정 중…" 같은 단계별 진행 상황**을 보여주고, **완료되면 자동으로 닫는다.**
   - 이유: 처리 중에 다른 조작이 안 먹혀 **버그처럼 보이는 것**을 막기 위함.
   - 참고: 공통 "오래 걸리는 동작 = 잠금 + 진행%"(docbox 피드백)과 같은 패턴. 공통 컴포넌트로.

2. **버전명 표시 — 창 왼쪽 맨 하단에 반드시**
   - 현재 판 버전(예: `v0.12.11`)을 좌하단 고정 표시.

3. **설정 맨 하단에 라이선스/정보 메뉴**
   - 설정 화면 맨 아래에 메뉴 1개 → 누르면 **MIT 라이선스 전문 등**을 보여주는 창(About/License) 띄우기.
