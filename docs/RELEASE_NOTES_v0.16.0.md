# LogiFlow 0.16.0 — Windows 판이 새 앱으로 바뀜

Windows 판이 새로 만든 앱으로 바뀌었다. 하는 일은 같고(가장자리로 밀어 채널 전환 · 클립보드 공유 · 로그인 전에도 실행), 더 가볍고 빠르다. Mac · Linux 는 0.15.0 그대로다(같은 파일을 다시 붙임).

## 받을 파일

| 파일 | 내용 |
|---|---|
| `LogiFlow-windows-setup.exe` | Windows 설치 파일(x64·ARM64 한 파일) — 늘 최신을 가리키는 이름 |
| `LogiFlow-v0.16.0-setup.exe` | 위와 같은 파일(판 번호 붙은 이름) |
| `LogiFlow-v0.16.0-win.zip` | 설치 없이 쓰는 실행 파일(x64·arm64) |
| `LogiFlow-v0.16.0-SHA256SUMS.txt` | 해시 |
| `LogiFlow-mac.dmg` · `LogiFlow-linux-x64.tar.gz` · `LogiFlow-linux-arm64.tar.gz` | 0.15.0 그대로 |

## 이전 판에서 바꾸기

1. `LogiFlow-windows-setup.exe` 를 실행한다. 이전 판(0.15.x)이 깔려 있으면 설치 화면에 「기존 LogiFlow(이전 판)를 지우고 이 판으로 바꿉니다」가 나오고, 이전 판을 조용히 지운 뒤 새 판을 깐다(관리자 승인 없음).
2. 처음 실행하면 이전 판 설정(별칭 · 배치 · 머무는 시간 · 테마 · 글자 크기 · 클립보드 · 로그인 자동 시작)을 그대로 이어받는다. 이전 판 설정 파일(`%APPDATA%\LogiFlow`)은 지우지 않는다.
3. 이전 판에서 「로그온 전에도 실행」을 켜 두었으면, 처음 실행 때 한 번 「이전 판에서 쓰던 「로그인 전에도 실행」을 켤까요?」를 묻는다. 「켜기」를 누르면 관리자 승인 한 번으로 이전 판 서비스·남은 파일을 정리하고 새 판 서비스를 켠다.
4. 이전 판이 남긴 서비스·예약 작업·파일이 있으면 전환 관리·진단 화면의 「기존 LogiFlow 정리」로 언제든 지울 수 있다.
5. 이전 판을 자동으로 지우지 못하면(드문 경우) 설치 끝에 안내가 뜬다 — Windows 설정 → 앱 → 설치된 앱에서 버전 0.15.x 인 「LogiFlow」를 지우면 된다.

이미 시험판(0.16.0-rs.N)을 쓰고 있었다면 그 자리에서 업그레이드된다(설정 그대로).

## 이전 판과 달라진 점

- 설정 창: 글이 잘리지 않게 다시 배치, 같은 기능은 한 곳에, 단추 이름은 동작만(처음 쓰는 사람 점검 반영). 글자 크기 작게·보통·크게가 실제로 달라짐.
- 「드래그 중 전환 안 함」(이제 「끌기 중 전환 막기」)이 실제로 적용됨.
- 앱을 지우면 「로그인 전에도 실행」 서비스·워커 사본·예약 작업·방화벽 규칙까지 정리(이전 판은 서비스를 남겼음).
- 클립보드 암호문구를 평문 대신 Windows 보호 저장(DPAPI)으로. 입력 칸은 ● 로 가리고 눈 아이콘으로 보기.
- 서비스가 켜진 채 배치·머무는 시간·끌기 막기를 바꿔도 바로 반영.
- 이 PC 주소에 어느 네트워크인지(유선·와이파이·가상 어댑터) 표시, 방화벽 허용 상태와 「허용 해제」.

이전 판과 클립보드를 주고받는 형식은 같다(이전 판이 깔린 PC 와도 그대로 주고받음).
