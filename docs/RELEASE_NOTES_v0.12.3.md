# LogiFlow 0.12.3

## x86 에서 「로그온 전에도 실행」 토글 꺼짐 — 근본 수정

증상: ARM 은 토글이 잘 유지되는데 x86 에서만 꺼짐(설치는 실제로 돼 로그온 전환은 동작).

원인: 상태 확인용 `schtasks /Query` 를 **출력 리디렉션 없이** 돌려, 콘솔 없는 트레이 앱에서 출력 핸들이 없어 일부 환경(x86)이 비정상 종료코드를 냄 → 설치됐는데 "미설치"로 오판 → 토글 꺼짐.

수정: `schtasks /Query` 출력을 리디렉션해 읽고 종료코드를 보도록 되돌림(PreLogon·ProbeTask 양쪽). 이제 x86 에서도 설치 후 토글이 유지됨.

## 유지

- 0.12.2 토글 즉시 재조회 제거, 0.12.1 클립보드 로그, 0.12.0 로그온/잠금 화면 전환 그대로.
