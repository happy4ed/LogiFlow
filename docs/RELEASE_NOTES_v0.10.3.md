# LogiFlow 0.10.3

## 업데이트 설치 시 이전 실행본 자동 종료

이전까지는 트레이에 LogiFlow 가 떠 있으면 파일이 잠겨 업데이트가 깔끔하지 않았다. 이제 설치 관리자가:

- Restart Manager(CloseApplications)로 먼저 정상 종료 시도 +
- 트레이 상주라 완전히 안 닫히는 경우를 대비해 **설치 직전 `taskkill /F /IM LogiFlow.exe /T` 로 강제 종료**(단일 인스턴스 뮤텍스도 해제).
- 제거 시에도 실행 중이면 먼저 종료.
- 설치 후 새 버전을 자동 실행.

→ **앞으로 새 setup.exe 를 그냥 실행하면 이전 프로세스를 알아서 끄고 새로 깔린다.** ('닫아주세요' 수동 프롬프트 뜨던 AppMutex 제거.)

## 유지
