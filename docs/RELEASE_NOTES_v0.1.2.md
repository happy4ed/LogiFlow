# LogiFlow 0.1.2

여러 기기 전수 탐색(키보드 포함). 여전히 읽기 전용(쓰기 없음).

## 바뀐 것

- 프로브 대상 확대: long(usage 0x0202, 20바이트) + short(usage 0x0201, 7바이트) 벤더
  컬렉션, 그리고 벤더 usagePage(0xFFxx)에 7바이트 이상 출력 리포트가 있는 인터페이스 모두.
- short 전용 인터페이스 지원: 인터페이스가 long 이 아니면 7바이트 short 리포트(0x10)로
  요청을 보낸다(기존엔 long 0x11 고정이라 short 전용 기기는 송신 실패).
- deviceIndex 0xFF(직접) + 1~6(리시버) 전수 핑, 잠자는 기기 고려해 1회 재시도.
- 각 인터페이스×deviceIndex 핑 결과(응답/타임아웃)를 로그에 한 줄씩 기록.
- 0x1814 미지원 기기도 목록에 표시(이름·VID:PID·연결·deviceIndex + "0x1814 미지원").
- 중복 제거: 같은 물리 기기가 여러 인터페이스로 잡히면 하나로(이름+index+연결 기준).

## 안 바뀐 것

- 읽기 전용 불변식 유지: 쓰기(func1 setHost) 코드 없음. 전송은 IRoot ping·getFeature·
  0x1814 func0·0x0005 뿐.
