# LogiFlow 0.12.11

## 콜드부팅 로그인 전 — BootTrigger 는 떴지만 기기가 자고 있어 전환이 부실하던 문제

0.12.10 으로 **콜드부팅 로그인 전에 워커가 뜨는 것은 확인**됐다(배터리 조건 제거 + BootTrigger 성공). 다만 로그에서 두 가지가 드러났다:

1. **기기가 잠들어 있음** — 로그인 전엔 로지텍 기기가 리시버에서 자고/끊겨 스캔이 `0개 → (움직여 깨운) 1개` 로 흔들림(로그인 후엔 2개). 자는 키보드는 전송 대상에서 빠짐.
2. **9초 지연** — 전환 순간에 느린 재스캔(≈9초)을 돌려 setHost 가 9초 뒤에야 나감 → 미는 순간 반응이 없어 "안 된다"로 느껴짐.

수정:

- **백그라운드 주기 스캔** — 로그온/잠금 화면에 있는 동안 백그라운드로 기기를 주기 스캔해(있으면 5초마다·없으면 1.5초마다) **깨어난 기기를 미리 목록에 채움**. 전환 순간엔 이 최신 목록에서 **즉시** setHost(9초 지연 제거).
- **일시적 0개는 직전 목록 유지** — 스캔이 잠깐 놓쳐도 이미 찾은 기기를 안 버림.
- 사용자 바탕화면(로그인 후 평상시)에선 스캔 안 함 — 트레이 앱과 HID 경합 방지.
- 전환가능 기기 수가 바뀌면 로그에 `N개 → M개` 로 표시(기기 깨어나는 과정 가시화).

## 한계(정직 고지)

로그인 전 화면에서 **안 건드린 기기(예: 키보드)는 계속 잠들어 있어** 그 순간엔 전환 대상에서 빠질 수 있다. 마우스를 움직이면 마우스는 깨어 전환되고, 키보드는 한 번 누르면 깨어 다음 밀기에 포함된다. 리시버가 이 PC 에 꽂혀 있어야 함은 동일.

## 적용법

0.12.11 설치 → 설정 "로그온 전에도 실행" 껐다 켜기(작업 갱신) → 콜드부팅. 로그온 화면에서 마우스를 **한 번 크게 움직여 깨운 뒤** 오른쪽 변으로 밀면 즉시 전환. 로그에 `전환가능 기기 … → 2개` 와 `setHost 전송 2개` 가 뜨는지 확인.
