# LogiFlow 0.12.5

## 클립보드 — 전각 문자 저장 버그 수정

증상: 로그에 `상대 １０．１１４．７２．４６` 처럼 IP·암호문구가 **전각 문자**(한글 IME 상태로 입력)로 저장돼 "알려진 호스트가 없습니다" + 수신 "인증 실패(암호문구 불일치)" 가 났다.

수정: 상대 주소·암호문구를 **반각으로 정규화(FormKC)** — 입력·저장·연결·키유도 전부. 한글 IME 로 입력해도 양쪽이 일치한다. (기존에 전각으로 저장된 값도 다음 적용 때 자동 교정.)

## 로그온 전환(ARM) — 디버그 로그로 추적

0.12.4 의 세션 잠금 플래그 + 상세 디버그 로그 그대로. ARM 에서 설정 → 「상세 디버그 로그」 ON + 「로그온 전에도 실행」 ON 후(깨끗한 적용 위해 **재부팅 권장**) 잠금/로그온 화면에서 밀어보고 `desktop-probe.log` 를 보면 `locked`/`active`/엣지 `dist`/HID 로 원인이 드러난다.
