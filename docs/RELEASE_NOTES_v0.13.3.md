# LogiFlow 0.13.3

회장님이 지시하신 남은 UX 2개를 마저 넣었습니다(버전명 좌하단은 0.13.0에서 완료).

## ① 오래 걸리는 토글 = 모달 + 단계 표시 + 완료 시 자동 닫기

"로그온 전에도 실행"을 켜고 끌 때 UAC 상승 + 서비스 등록/제거로 몇 초 걸리는데, 그동안 창이 멈춘 듯 보이고 다른 걸 눌러도 반응이 없어 버그처럼 보였다.

- 이제 누르면 **모달이 뜨고 단계가 표시**된다: `채널 배치 저장 중…` → `관리자 권한 요청 → 서비스 등록 중… (UAC 창에서 '예')` → `마무리 중…`.
- 처리 동안 **다른 조작은 막히고**(모달), 끝나면 **자동으로 닫힌 뒤** 결과 메시지가 뜬다.
- 실제 작업은 백그라운드 스레드에서 돌아 UI 가 얼지 않는다.

## ② 설정 맨 아래 라이선스(MIT) 메뉴

설정 맨 아래 "정보 → 오픈소스 라이선스 [보기]" 추가. 누르면 **MIT License 전문 + 사용 기술(.NET Framework·WinForms·Windows HID/HID++ 0x1814·Inno Setup)** 을 스크롤 창으로 보여준다. 저장소 루트에 `LICENSE`(MIT) 파일도 추가했다.

## 유지

0.13.2 로그온 예약 작업 자동시작, 0.13.1 churn 수정, 0.13.0 윈도우 서비스 전환 그대로.
