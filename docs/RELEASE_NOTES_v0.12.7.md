# LogiFlow 0.12.7

## 로그온 화면 전환 — 트리거 안 되던 문제 수정 (핵심)

디버그 로그에서 확인: 잠금 화면에서 커서가 변에 닿아 `dist=0 band=Y dwell=1.00` 까지 가도 전환이 안 됐다.

원인: 전환 조건에 "바깥으로 10px 밀기(MinPushPx)"가 있는데, **커서가 화면 끝에 박히면 더 못 나가** 폴링(GetCursorPos)으론 밀기를 못 읽는다. (사용자 세션은 raw 입력이라 밀기를 읽음)

수정: 로그온 워커는 **밀기 요건을 빼고 "변에서 dwell 채우면 전환"**. → 잠금/로그온 화면에서 변에 밀면 전환됨.

## 로그인 전·재부팅 대비

- **워커 exe 를 머신 공용 경로(ProgramData)로 복사해 실행**: 로그인 전엔 사용자 %LocalAppData% 가 안 올라와 SYSTEM 이 그 경로 exe 를 못 찾던 문제(워커 미실행·로그 없음) 해결.
- **트레이 자동 시작을 설치 시 HKCU Run 에 직접 등록**: 재부팅 후 프로그램이 안 뜨던 문제 보강.
