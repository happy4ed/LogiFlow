# LogiFlow 0.5.0

UI 다듬기(회장님 10-21 실기 피드백). 기능·안전·캐시·트레이·아이콘·설치파일은 0.4.0 그대로.

## 바뀐 것

- 폰트 최소 크기 원칙: 앱 전역에서 최소 ≈12.7px(9.5pt) 이상 보장. 라벨·표·캔버스 라벨·
  메뉴·배지 등 모든 텍스트가 최소 이상. 모든 Font 생성을 `UiFont.Get` 으로 통일해 최소크기
  바닥을 적용.
- 글자 크기 설정: 설정 「모양」 그룹에 글자 크기(보통 100% · 크게 120% · 아주 크게 140%).
  선택 시 앱 전역 폰트 스케일 적용(ThemedControls·표·캔버스 포함)·저장. 스케일을 낮춰도
  최소 크기 미만으로는 내려가지 않음.
- 전환 관리 캔버스 높이 확대(240 → 320px). 모니터·채널 박스가 더 크게.
- 커스텀 테마 스크롤바: 네이티브 OS 스크롤바 대신 라이트/다크 색의 얇은 세로 스크롤바
  (ThemedScrollPanel + ThemedScrollBar). 세로 전용, 드래그·휠 지원.
- 가로 스크롤 0: 콘텐츠 폭을 창(뷰포트) 폭에 맞춰 반응형 레이아웃. 스크롤바 자리를 항상
  예약해 폭 요동 없음. 가로 스크롤바 생기지 않음. 창을 넓히면 콘텐츠도 넓어지고, 필요 시
  세로만 스크롤.

## 그대로(0.4.0)

- 기능(엣지 자동 전환·수동 전환)·안전(setHost 가드)·기기 캐시·트레이 전환·아이콘·설치파일.

## 제약

- 실기 미검증(빌드 CI windows-latest · UI 는 회장님 실기 필요). 큰 글자에서 일부 행 간격이
  빡빡할 수 있으나 세로 스크롤로 넘침 흡수.
