# LogiFlow+ 0.14.3 (B안 테스트 프리릴리스)

**정식 아님 — B안 실기 테스트용.** 0.14.2 지적 두 가지를 고침.

## 1. glow 최고점 = setHost 가 실제로 나간 순간

- dwell 동안은 80% 밝기까지만 오름. 전환 요청 뒤 90% 로 기다림.
- setHost 쓰기가 성공한 바로 그 순간 흰빛 최고점을 한 번(약 50ms) 보이고 사라짐.
- 전환이 실패하면 최고점 없이 흐려지고, 변에서 떼지 않고 계속 밀면 다시 시도.

## 2. 간헐적으로 glow 는 났는데 안 넘어가던 문제

원인 후보(코드 확인):

- 기기마다 ping 200ms + 확인 300ms 를 기다린 뒤 다음 기기로 넘어가 두 번째 기기가 0.5초 이상
  늦게 넘어갔다. 0.14.2 는 glow 를 요청 순간에 지워서 "효과는 났는데 안 넘어감"으로 보였다.
- 바탕화면 워커의 백그라운드 스캔이 5초마다(스캔 한 번에 수 초) 리시버에 HID++ 핑을 보내
  거의 상시 점유 — setHost 와 겹치면 리시버가 명령을 놓칠 수 있다. (로그온 워커는 같은 이유로
  바탕화면에서 스캔을 안 하고 있었다.)
- 전환 진행 중에 다시 밀면 그 요청은 버려졌는데 화면엔 표시가 없었다.

고친 것:

- 모든 기기에 setHost 를 대기 없이 먼저 연달아 보내고, 확인은 그 뒤에 한꺼번에(실패한 기기만 깨워서 재시도).
- 백그라운드 스캔: 기기가 있으면 60초마다만, 전환 중·전환 뒤 10초는 안 함.
- 건너뛴 요청·실패는 glow 를 흐리게 끝내 성공과 구분.

## 테스트

1. 0.14.3 설치("로그온 전에도 실행" 켠 상태 유지).
2. 변으로 밀기 → 점점 밝아지다 **넘어가는 순간 흰빛 최고점 → 바로 사라짐**인지.
3. 여러 번 왕복해 **glow 만 나고 안 넘어가는 경우**가 남는지. 남으면 그 시각의 워커 로그
   (`[바탕화면 전환]` 줄과 기기별 `시도N 쓰기=… 확인=…` 줄) 붙여 주기.
