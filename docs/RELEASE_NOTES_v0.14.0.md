# LogiFlow+ 0.14.0 (B안 테스트 프리릴리스)

**정식 아님 — B안 실기 테스트용 프리릴리스.** 지금까지(0.13.5)는 그대로 두고 전환 로직만 B로 바꿨습니다.

## 바뀐 것 — 데스크탑 공백 제거(서비스 단일 전담)

지금까지(main): 로그인하면 바탕화면 전환을 트레이 앱이 맡아, **트레이 뜨는 틈 = 공백**이 있었습니다.

0.14.0(B안): **서비스가 바탕화면 전환까지 전담**합니다.

- 서비스가 세션마다 워커 둘을 상주시킵니다: **로그온/잠금 화면**은 기존 폴링 워커, **바탕화면**은 새 raw 워커(`winsta0\default`). 각 워커는 자기 화면일 때만 동작해 **중복 전환이 없습니다**.
- 바탕화면 워커는 트레이와 똑같은 **raw input(실제 밀기)** 판정을 씁니다 → 커서를 가장자리에 그냥 둬도 전환되던 오작동 없이, 의도적으로 밀 때만 전환.
- "로그온 전에도 실행"이 켜져 있으면 **트레이의 엣지 감시는 끕니다**(서비스가 전담하므로 중복 방지). 트레이는 설정·수동 전환·메뉴 전용이 됩니다.
- 로그인 직후 서비스 워커가 이미 바탕화면에 상주하므로 **공백이 없어집니다**.

## 테스트 포인트

1. 0.14.0 설치 → "로그온 전에도 실행" **켜기**(서비스 등록).
2. **콜드부팅/로그인 직후** 바탕화면에서 가장자리로 밀기 → 트레이 뜨기 전에도 전환되는지(공백 없는지).
3. 바탕화면에서 **커서를 가장자리에 그냥 둬도** 전환 안 되는지(의도적 밀기만).
4. **로그온 화면/잠금**에서 전환은 그대로 되는지(기존 폴링 워커).
5. 여러 번 밀 때 **중복 전환(한 번에 두 번)** 없는지.

## 아직 안 된 것(다음)

- 바탕화면 glow 오버레이(변에 닿을 때 빛나는 효과)는 서비스 워커로 아직 안 옮김 — 트레이 감시를 끄면서 바탕화면 glow 가 잠깐 빠졌습니다(전환 동작엔 무관). 테스트 결과 보고 B-3에서 서비스 워커가 glow 를 그리게 할 예정.
- 화면보호기(secure) 중 전환은 엣지 케이스(풀면 복귀).

## 피드백 주시면

오작동·공백·중복 전환 여부 알려주시면 반영해서 정식(main)으로 올립니다.
