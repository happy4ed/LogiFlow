# LogiFlow 0.9.1

전환 관리 레이아웃 바로잡기(회장님 시안 승인 반영).

## 전환 관리 — 폭/캔버스

- 기본 폭 = 채널 별칭 줄 폭. 캔버스·등록 기기 행·하단 막대가 모두 같은 폭에 정렬.
- 모니터 배치 캔버스: 보이는 영역(pane)에 **꼭 맞게 축소/정렬** — 평소(모니터 1~3개)엔 전부 보이고 스크롤 없음.
  모니터가 아주 많아 더 줄일 수 없을 때만 그 칸이 좌·우·상·하로 스크롤(0.9.0 의 과대 스케일·강제 스크롤 제거).
- 미배치 채널(예: 채널 2)은 캔버스 아래쪽 "미배치" 영역에 박스로 보이며, 끌어서 모니터 변에 붙이면 자동 전환 변이 됩니다.

## 유지

- 0.9.0 의 버튼 폰트 통일·토글 키움·진단 머리줄·새로 고침 피드백·탭 전환 속도 개선 그대로.
- 쓰기(전환)는 0x1814 func1 setHost 하나뿐 · HostSwitcher 경유 · (a)지원 (b)범위 (c)명시 트리거만.
