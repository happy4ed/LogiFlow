# LogiFlow 0.7.0

## 글자 크기 3단(pt 가산)

- 설정 → 글자 크기: **작게 · 보통 · 크게**. 기존 대비 작게 −1pt · **보통 +1pt(기본)** · 크게 +3pt.
- 전과 달리 비율(%) 스케일이 아니라 기준 크기에 pt 를 더하는 방식. 최소 크기(≈12.7px) 보장은 그대로.

## 앱 가로 확대 · 배치 캔버스 잘림 제거

- 창 기본 크기 1120×650(최소 980×600) — 전환 관리 화면이 가로로 넓어져 모니터 배치가 왼쪽부터 다 보임.
- 모니터 배치 캔버스 여백을 **모니터 1칸 이상**(가로 1.3칸 · 세로 1.6칸) 확보 — 변에 붙인 채널 박스와 라벨이 캔버스 밖으로 잘리지 않음.
- 아래 미배치 채널 박스는 한 줄에 **개수만큼 폭을 줄여 전부 표시** — 채널 3까지 잘리지 않음(가로 스크롤 없음).
