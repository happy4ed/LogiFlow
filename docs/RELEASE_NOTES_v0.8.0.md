# LogiFlow 0.8.0

## 로그온 전에도 실행(선택 · 기본 꺼짐)

- 설정 → 실행 → **로그온 전에도 실행** 토글. 켜면 UAC 상승 후 SYSTEM 권한 '시작 시(ONSTART)' 예약 작업을 설치합니다.
- 부팅 시(로그인 화면 전) LogiFlow 가 짧게 떠서 **마우스·키보드를 이 PC 채널로 당깁니다** — 그 PC 앞에서 바로 로그인할 수 있게.
- 이 PC 채널은 [진단] 새로 고침으로 한 번 읽히면 자동 저장됩니다.

### 한계(정직 고지)

- 전환 명령은 **리시버/동글이 이 PC 에 꽂혀 있고** 기기가 다른 채널에 있을 때만 도달합니다.
- 잠금/로그인 화면에는 커서가 없어 **가장자리(엣지) 전환은 되지 않습니다** — 이 기능은 부팅 시 '이 PC 로 당기기'만 합니다.
- 설치·삭제는 **관리자 권한(UAC)** 이 필요하며, 회사 정책으로 막혀 있으면 설치가 실패합니다(토글이 되돌아갑니다).

## 유지

- 쓰기(전환)는 여전히 0x1814 func1 setHost 하나뿐 · `HostSwitcher` 경유 · (a)지원 (b)범위 (c)명시 트리거만. 로그온 전 경로도 같은 안전 경로를 씁니다.
- 0.7.0 글자 크기 3단·앱 가로 확대·캔버스 잘림 제거, 0.6.0 엣지 glow/tension 그대로.

## macOS

- macOS 설치파일은 이미 `mac-v0.1.0` 릴리스에 `.dmg` · `.zip` 으로 제공 중(읽기 전용 진단판).
- 전환·엣지·로그인 항목(LaunchAgent)은 회장님 Mac 에서 기기 읽기가 확인된 뒤 키웁니다.
