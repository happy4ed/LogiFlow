# LogiFlow 0.9.0

회장님 화면 피드백 반영 — UI 다듬기 + 로그온 전 기능 정정.

## 디자인 일관성

- **버튼 폰트 전부 동일**: 모든 버튼이 같은 크기(9pt)로 통일. 「새로 고침」·「로그 폴더 열기」만 크던 문제 해결(Form 폰트 상속 제거).
- **토글 키움**: on/off 스위치 28×16 → 40×22.

## 전환 관리 — 폭/배치

- 콘텐츠 열 폭 상한(≈560px) — 창이 넓어도 과하게 벌어지지 않음. **등록된 기기 행**이 창 끝까지 늘어나던 문제 해결.
- 창 기본 크기 820×660(최소 760×600)로 정돈.
- **모니터 배치 캔버스**: 적정 크기로 고정, 모니터가 늘어 넘치면 **그 영역만 상하좌우 스크롤**(고정 스케일 + AutoScroll). 전처럼 전부 축소되지 않음.

## 진단

- **「모두 보기」 토글 잘림 해결** — 머리 줄 재배치(토글·새로 고침·로그 폴더가 안 겹침).
- **새로 고침 피드백**: 누르면 즉시 버튼이 「스캔 중…」으로 바뀌고 비활성화 → 끝나면 복귀. (전엔 아무 반응 없어 갑갑)

## 로그온 전에도 실행 — 정정

- 이전 판(0.8.0)의 '부팅 시 이 PC 로 당기기'는 **회장님이 원한 동작이 아니었음** — 끄기도 동작 안 하던 버그 포함.
- 이번 판: **끄기가 확실히 동작**(이전 판 설치분을 제거) · 켜도 지금은 아무것도 설치하지 않고 안내만 표시.
- 진짜 목표(로그인 화면에서 엣지 전환)는 윈도우 보안 화면(Winlogon) 접근이 필요 — **방식 확정 후 별도 제공**.

## 유지

- 쓰기(전환)는 0x1814 func1 setHost 하나뿐 · HostSwitcher 경유 · (a)지원 (b)범위 (c)명시 트리거만.
- 0.7.0 글자 크기 3단, 0.6.0 엣지 glow/tension 그대로.

## macOS

- 읽기 전용 **디버그 도구**는 `mac-v0.1.0` 에 별도 유지(.dmg/.zip). 다음부터 윈도우+맥 릴리스는 하나로 합칠 예정(맥이 실앱 될 때).
