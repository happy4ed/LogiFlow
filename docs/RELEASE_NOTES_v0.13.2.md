# LogiFlow 0.13.2

## 로그인 직후 데스크탑 전환 공백 줄이기 (B안)

콜드부팅 로그온 화면 전환은 서비스가 맡아 잘 되는데(0.13.1 확인), **로그인해서 바탕화면에 들어온 뒤 트레이 앱이 뜨기 전까지** 데스크탑에서 전환이 안 되는 공백이 있었다. 데스크탑 전환은 트레이 앱이 담당하는데(민 동작을 raw 입력으로 정확히 읽어 커서를 끝에 잠깐 둔 것과 구분), 그 트레이가 윈도우 자동시작(HKCU Run)의 지연 때문에 로그인 몇 초 뒤에야 떴기 때문이다.

수정 — 트레이 자동시작을 **로그온 예약 작업(LogiFlow-Tray, ONLOGON)** 으로 바꿔 Run 지연 없이 로그인 직후 바로 뜨게 했다.

- 예약 작업은 현재 사용자 계정 · 비상승(일반 권한) · 로그온 트리거. 관리자 권한 불필요.
- 기존 HKCU Run 은 **보조로 유지** — 예약 작업이 정책으로 막힌 환경 대비.
- 트레이는 단일 인스턴스 뮤텍스가 있어 둘 다 떠도 트레이는 하나만 뜬다.

역할 분담은 그대로다: **서비스**가 부팅·로그온·잠금 화면을 책임지고(존재가 안정적), **트레이**가 데스크탑을 책임진다(판정이 정확). 이번 판은 그 트레이를 더 빨리 띄워 공백만 좁혔다.

## 적용·확인

0.13.2 설치 → (자동시작이 켜져 있으면 그대로, 꺼져 있었다면 한 번 켜 주세요) → 로그아웃했다 다시 로그인. 로그인하자마자 트레이가 떠서 데스크탑 변 밀기 전환이 바로 되는지 보세요. 예약 작업 확인은 작업 스케줄러에서 `LogiFlow-Tray` 로 보입니다.
