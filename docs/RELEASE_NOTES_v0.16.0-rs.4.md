# LogiFlow 0.16.0-rs.4 — Windows 러스트 판(작은 수정)

rs.3 회장님 PC 첫 실기 통과(11-16, 원문 "오 동작 잘된다. 용량도 적고") 뒤의 작은 수정판. 아래 두 가지만 바꿨고 그 밖의 동작·화면은 rs.3 그대로다.

## 받을 파일

| 파일 | 내용 |
|---|---|
| `LogiFlowRs-v0.16.0-rs.4-setup.exe` | 설치 파일(x64·ARM64 한 파일) |
| `LogiFlowRs-v0.16.0-rs.4-win-x64-arm64.zip` | 실행 파일만(x64·arm64 각 1개) |
| `LogiFlowRs-v0.16.0-rs.4-SHA256SUMS.txt` | 해시 |

## 1. 포터블 zip 에 로그 파일이 섞여 나가던 것

- 원인: CI 의 실행 시험이 배포 폴더의 실행 파일을 직접 띄워, 그 옆에 생긴 `x64/logs/logiflow-diag.log` 가 zip 에 함께 묶였다(rs.3 zip). 설치 파일은 실행 파일을 하나씩 지정해 담으므로 로그가 들어가지 않았다.
- 고침: 실행 시험·화면 캡처는 임시 사본에서 돌린다. 묶기 전에 배포 폴더에 실행 파일 2개 말고 다른 것이 있으면 CI 가 실패하고, 묶은 뒤 zip 안에 `logs/` 나 `.log` 가 있거나 실행 파일이 2개가 아니면 실패한다.

## 2. rs.3 「남은 일」 4건(8차 첫 사용 점검)

| 무엇을 | 어떻게 |
|---|---|
| 이 PC 주소에 어느 네트워크인지 표시가 없음 | 주소마다 「유선 랜(이더넷) 주소입니다」·「와이파이(Wi-Fi) 주소입니다」·「가상 어댑터(vEthernet (WSL)) 주소입니다」를 적고, 실제 랜·와이파이 주소를 먼저, 가상 어댑터 주소는 뒤에 「다른 PC 와 연결할 때는 보통 쓰지 않습니다」. Windows 어댑터 목록(GetAdaptersAddresses)에서 읽고, 못 읽으면 예전처럼 이름 없이 |
| 클립보드 공유를 끄면 방화벽 줄도 숨음 | 공유를 꺼도 허용 규칙이 남아 있으면 「Windows 방화벽」 줄은 남겨 「허용 해제」할 수 있게 |
| 트레이 채널 항목에 동사가 없음 | 「채널 2 · 노트북으로 모두 전환」. 창의 채널 메뉴도 「…으로 전환」·「…으로 모두 전환」. 조사는 이름 끝소리에 맞춤(「채널 3으로」) |
| 「채널 모두 떼기」와 「사용」 스위치가 같은 결과 | 「사용」 스위치 하나만 남기고 「채널 모두 떼기」 단추는 뺐다(잠깐 끄려던 사람이 배치를 지우지 않게). 하나씩 떼기는 상자를 멀리 끌어 놓기, 실수는 「되돌리기」 |

C# 판과 주고받는 형식(클립보드 프레임 · `config.txt` · `devices.txt`)은 바뀌지 않았다.

## 실기 확인 대기

- 네트워크 이름 표시(회장님 PC 의 실제 어댑터 이름·순서)
- 트레이 메뉴 「…으로 모두 전환」 동작(rs.3 과 같은 경로)
