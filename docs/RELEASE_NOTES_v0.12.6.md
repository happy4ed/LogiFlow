# LogiFlow 0.12.6

## 이미지 클립보드 무한 핑퐁 긴급 수정

증상: 이미지를 클립보드 공유하면 두 PC 사이에서 무한 반복 전송.

원인: 받은 이미지를 클립보드에 넣고 다시 읽으면 PNG 재인코딩으로 바이트가 달라져, 해시 기반 에코 가드가 "새 내용"으로 오판 → 서로 끝없이 되보냄.

수정: **수신 적용 직후(1.2초) 생기는 내 클립보드 변화는 되돌려 보내지 않음**(시간창 억제). 텍스트·이미지 모두 핑퐁 차단.

## 유지

- 0.12.5 전각 정규화, 0.12.4 ARM 잠금 감지·디버그 로그 그대로.
