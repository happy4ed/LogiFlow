# LogiFlow 0.11.1

## 클립보드 공유 (LAN 직접 연결 · 텍스트·이미지)

다른 서브넷이어도 **상대 PC IP 를 직접 지정**해 클립보드를 주고받는다(자동 탐색 대신 직접 연결). 윈도우 내장 클라우드 클립보드가 막힌 환경용.

- 설정 → **클립보드 공유**: 사용 토글 · 상대 PC 주소(IP/호스트명) · 암호문구.
- 양쪽 PC 에 서로의 주소 + **같은 암호문구** 입력 → 한쪽에서 복사하면 상대 클립보드에 자동 반영(텍스트·이미지, 8MB 이하).
- 보안: 암호문구에서 유도한 키로 **AES-CBC 암호화 + HMAC-SHA256 인증** — 암호문구가 다르면 전달 안 됨. 엿보기·위조 방지.
- 방화벽: 수신 포트(기본 48737) 허용 필요(첫 실행 시 윈도우가 물어보면 허용).
- 에코 루프 방지(받은 내용은 되돌려 보내지 않음).

## 로그온 화면 접근 테스트 — 가능 입증

0.10.4 프로브에서 **잠금/로그인(Winlogon) 보안 화면에서 커서 읽기 성공**(SetThreadDesktop 성공 + GetCursorPos 좌표 변함) 확인. 로그인 화면 엣지 전환 구현의 핵심 전제가 검증됨(다음 판에서 실제 전환 구현 예정).

## 유지

- 0.10.3 업데이트 시 이전 실행본 자동 종료, 전환 관리 레이아웃 그대로.

## 로그온 화면 HID 접근 테스트 추가 (ARM 잠금화면 전환 진단)

프로브가 winlogon 데스크톱 SYSTEM 컨텍스트에서 **HID(=setHost 가 쓰는 경로)를 읽을 수 있는지 1회 테스트**(읽기 전용·setHost 안 보냄)해 로그에 남긴다. 기기 개수·0x1814 인덱스·현재 채널. x86/ARM 로그를 비교해 "ARM 잠금화면 전환 실패"가 HID 접근 문제인지 다른 문제인지 가린다.

(0.11.0 의 클립보드 공유 네임스페이스 충돌 빌드 오류도 수정.)
