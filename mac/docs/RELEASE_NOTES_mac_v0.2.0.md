# LogiFlow macOS 0.2.0 (전환·변 밀기·glow · 실기 미검증)

윈도우판 0.14.3 의 핵심을 Mac 으로 옮긴 첫 판. 0.1.0(읽기 진단)도 Mac 실기 확인 전이라,
이 판 하나로 읽기·전환·변 밀기를 한 번에 확인한다.

## 들어간 것

- 채널 전환: 창의 「채널 N 으로」 버튼 · 메뉴 막대(⇄ 아이콘) → 마우스·키보드 함께 넘김.
  전송은 윈도우 0.14.3 과 같음(전 기기 setHost 연달아 → 확인 → 실패 기기만 깨워 재시도).
- 변으로 밀어 넘기기: 채널마다 「화면 · 변」 고르기 → 커서를 그 변에 대고 바깥으로 0.5초 밀면 전환.
  마우스 이벤트만 보므로 손쉬운 사용 권한 불필요(예상).
- glow: 미는 동안 변이 점점 밝아지고, setHost 가 실제로 나간 순간 흰빛 최고점 → 바로 사라짐.
- 메뉴 막대 상주 — 창을 닫아도 계속 동작. 종료는 메뉴의 「종료」.

## 실행(미서명)

처음 한 번: Finder 에서 LogiFlow.app 우클릭 → 열기 → 열기. (또는 `xattr -dr com.apple.quarantine LogiFlow.app`)

## 확인 부탁

1. 창의 「기기」에 마우스·키보드가 나오고 「채널 수 · 현재 채널」이 맞는지.
2. 「채널 N 으로」 버튼 → 둘 다 넘어가는지.
3. 「변으로 밀어 넘기기」에서 채널을 화면 변에 배정 → 밀었을 때 glow 후 넘어가는지.
4. 안 되면 창 아래 로그 경로(`~/Library/Logs/LogiFlow/logiflow-diag.log`) 파일을 보내 주기.
